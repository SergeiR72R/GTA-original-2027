# 3D-модели и достопримечательности

## Коротко

Для 3D-моделей в игре MCP не обязателен. Здания, башни, купола и трубы
Claude строит прямо в коде из простых объёмов: коробок, цилиндров,
многоугольников и их стопок. Так уже сделаны Азриэли, часовая башня Яффо и
11 достопримечательностей ниже. Они одинаково работают в 3D и в 2D, ничего не
весят и не требуют загрузки файлов. Стиль — «блочный», в духе GTA2.

Внешний 3D-редактор (Blender через MCP) нужен, только если хочется
**детальных** моделей: резьба, арки, скруглённые купола, лодки, сложные
крыши. Как это сделать — в разделе «Детальные модели» ниже.

## Детальные модели: Claude строит их сам (Blender без окна)

Так сделаны **все знаковые здания** (мечеть Хасан-Бек — `tools/models/hassanbek.py`, остальные — `tools/models/landmarks.py`) и **три типовых дома** Тель-Авива: баухауз на сваях со скруглёнными балконами, дом 1960-х со ставнями на балконах и бойлерами, эклектика 1920-х с зелёными ставнями. Дома заменяют в 3D примерно 45% обычных коробок своего стиля (2–3 клетки), фасадом к улице. Claude ставит Blender как
модуль Python (`pip install bpy`) прямо в облачной сессии и строит модель
скриптом — редактор на компьютере не нужен.

* Скрипт модели — `tools/models/<имя>.py`: строит здание из простых
  частей (коробки, призмы, купола, стрельчатые арки), рендерит превью
  (`--render папка`) и пишет геометрию в `assets/models/<имя>.js`.
* Игра читает этот файл как обычный скрипт, поэтому всё работает и при
  открытии с диска. В 3D модель заменяет простые объёмы здания
  (`City.models`, `R3.model`); стены для столкновений и 2D-режим — прежние.
* Масштаб: 1 клетка = 4 м; по высоте 1 м = `MODEL_HS` единиц 3D (дома в
  игре выше настоящих).
* Пересобрать: `python tools/models/landmarks.py [имя ...] [--render папка]`
  и `python tools/models/hassanbek.py` (нужен `bpy` под Python 3.13).
* Высота выше 24 м сжимается (как у высоток в игре), иначе башни упираются в камеру.

## Детальные модели: три пути

### Путь 1. Claude строит модель в Blender (Blender MCP)

Claude управляет Blender на вашем компьютере: создаёт геометрию,
материалы и экспортирует `.glb`.

**Важно:** облачная сессия Claude Code (как эта) не видит ваш компьютер.
Blender MCP работает с Claude, запущенным **на том же ПК**, что и Blender:
Claude Code в терминале или Claude Desktop.

1. Поставьте [Blender](https://www.blender.org/) 3.0 или новее, Python 3.10+
   и менеджер пакетов `uv`. В Windows: `winget install astral-sh.uv` или
   инструкция на сайте uv.
2. Скачайте `addon.py` из репозитория
   [ahujasid/blender-mcp](https://github.com/ahujasid/blender-mcp). В Blender:
   Edit → Preferences → Add-ons → Install (в новых версиях — Install from
   Disk) → выберите `addon.py` и включите его. На боковой панели (клавиша N)
   появится вкладка BlenderMCP — нажмите в ней кнопку подключения.
3. Подключите сервер к Claude:
   * Claude Code: `claude mcp add blender uvx blender-mcp`
   * Claude Desktop: в Settings → Developer → Edit Config добавьте сервер
     `blender` с командой `uvx` и аргументом `blender-mcp` (точный пример —
     в README репозитория).
4. Откройте папку игры в Claude Code и попросите, например:
   «Построй в Blender low-poly модель „Электростанция Ридинг“ по описанию из
   3D_MODELS.md, соблюдай требования к моделям и экспортируй в
   `assets/models/reading.glb`».

В Blender MCP есть генерация моделей через Hyper3D Rodin и загрузка готовых
ассетов (Poly Haven, Sketchfab). Для них нужны настройки в панели аддона, а
для некоторых — ключ или аккаунт соответствующего сервиса.

### Путь 2. Картинка → 3D-модель (генераторы по изображению)

1. В Gemini сгенерируйте концепт достопримечательности по шаблону ниже.
2. Загрузите картинку в сервис «изображение → 3D» (Hyper3D Rodin, Meshy,
   Tripo и подобные; нужен аккаунт, условия бесплатного использования у всех
   разные).
3. Скачайте модель в `.glb`. Если в ней больше 10 тыс. треугольников —
   уменьшите в Blender (модификатор Decimate) или попросите Claude сделать
   это через Blender MCP.

Это можно поручить **Claude в Chrome** — задание ниже.

### Путь 3. Вручную в Blender

По тем же требованиям, что ниже. Подойдёт, если вы или знакомый моделлер
работаете в Blender.

## Требования к моделям

* Формат `.glb` (glTF binary), текстуры встроены, не больше 1024×1024.
* До **8 000 треугольников** на здание (лучше 2–5 тыс.), один-три материала.
* Реальные пропорции, единицы — метры. Масштаб под участок в игре Claude
  подгонит сам (1 клетка ≈ 4 м).
* Начало координат — центр основания на уровне земли, ось Y вверх.
* **Главный фасад смотрит на юг (+Z)**: камера в игре смотрит с юга под
  наклоном, этот фасад будет виден чаще всего.
* Без земли, деревьев, людей и машин вокруг — только здание.
* Имя файла — из таблицы ниже, папка `assets/models/`.

Когда положите модели в `assets/models/`, напишите Claude. Он подключит
загрузчик glTF и встроит модели в `bundle.js`, чтобы игра работала и при
открытии с диска. Модель заменит процедурную версию, а если файла нет —
останется процедурная.

## Шаблон промпта для концепта в Gemini

```
Isometric three-quarter view of [ОПИСАНИЕ ИЗ ТАБЛИЦЫ НА АНГЛИЙСКОМ],
stylized low-poly game asset for a top-down crime game set in Tel Aviv,
clean simple shapes, flat colours with light texture, whole building visible
from base to top, single building centered, plain white background, soft
daylight, no ground, no trees, no people, no cars, no text, no logos.
```

Описание переведите на английский и вставьте вместо скобок. Пример для маяка:
`the old Jaffa lighthouse: a slim white tower with red bands and a glass
lantern on top, standing on a small sandstone house`.

## Задание для Claude в Chrome (концепты и модели)

> Откройте этот раздел в боковой панели Claude в Chrome и скажите
> «Выполни задание из раздела».

1. Открой https://gemini.google.com. Для каждой строки таблицы «Список
   моделей» сгенерируй концепт по шаблону промпта (описание переведи на
   английский). Скачай одну удачную картинку на здание, строго в порядке
   таблицы. Проверь: здание целиком, белый фон, без текста.
2. Если пользователь назвал сервис «изображение → 3D» и вошёл в аккаунт:
   загрузи туда концепт, выбери режим с низким числом полигонов (low poly,
   до 10 000), дождись модели и скачай её в формате GLB. Переименовать файл
   нельзя — запиши в отчёт, какой скачанный файл какому зданию соответствует.
3. Не трать платные кредиты без подтверждения пользователя.
4. В конце отчёт: что готово, что пропущено, соответствие файлов зданиям.

Скачанные модели переименуйте по таблице и положите в `assets/models/`.
